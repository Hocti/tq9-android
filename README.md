# 九万輸入法 TQ9 (Android)

用九方 **已過期** 的專利 HK1035043 製作的 numpad 式中文輸入法，
由 Windows 版 [`/mnt/d/dev/Q9/TQ9/`](../TQ9/) 改寫成 Android system keyboard (Kotlin)。

以 numpad 輸入 2~3 鍵即可開始選字，字碼表、關聯字、同音字全部由一個 sqlite 檔案提供，
可以喺 app 入面隨時換走。

---

## 撳邊度做乜

### 中文 view（本體）

```
[⭐速選/长撳简]   7 8 9   [⚙ bar]
[🔈同音/长撳關聯] 4 5 6   [⌫]
[🔡英數]          1 2 3   [␣]
[🌐]            [ 0 ][✖]  [⏎]
```

九宮格跟足 numpad 排法（7 8 9 喺最上），同 Windows 版一模一樣。

| 鍵 | 單撳 | 長撳 |
| --- | --- | --- |
| `0` | 標點 / 姓氏 / 選字 / 下頁（跟住狀態變） | **開關標點**（「」（）《》…），即係原本 `/` 鍵 |
| `⭐` 左上角 | 速選字表（首頁 = 表 1000，撳咗 1~9 之後 = 表 1001~1009）；選字時 = 上一頁 | 切換簡體輸出 |
| ↑ 呢粒 | **短撳同長撳做乜都可以喺設定頁換**：速選字／簡體開關／emoji／貼上／錄音／AI／無效。短撳唔准揀「無效」，短撳同長撳亦都唔可以做同一件事 | |
| `🔈` | 同音字**開關**（著咗會變藍）。淨係 toggle，唔會換走而家個字表 —— 照打碼、揀字，揀嗰下先至彈出嗰個字嘅同音字表 | 關聯字 |
| `🔡` | 轉英文 view | |
| `🌐` | 轉下一個輸入法 | 開輸入法揀選視窗 |
| `⚙` | 上面條 bar：關 → 候選字 → 工具 → 關 | |
| `⌫` | 未打完嘅碼 → 剷返一碼；選字中 → 取消；否則先至真係刪字 | |
| `␣` | 選字中 = 揀第一個；否則入空格 | **唔好放手，上下左右拖住郁 caret** |
| `⏎` | 有碼未打完 = 取消；否則 enter / 送出 | |
| `✖` | 取消 | |

**九宮格長撳 = 連撳**（`1`~`9`）：長撳 `7` 就係打咗兩個 `7`，
所以「長撳 `7` 再拉去 `0`」= `770`；滑到最後一格停一停先放手都一樣算兩下
（`8` 拉去 `1` 停一停 = `811`）。`0` 冇呢個行為，因為佢長撳係開關標點。

**用同音字打完一個字之後**，同音鍵左上角會寫返嗰個字**正路應該點打**（字碼），
下次唔使再兜同音字。再打多一個普通字就自動清走。

`🎤` 錄音搬咗上工具 bar（喺 `📋` 隔籬），左上角嗰粒鍵亦都揀得做錄音。

### 上面條 bar（撳 `⚙` 轉）

三段轉，**每段都係得一行**，所以轉嚟轉去個鍵盤都唔會跳高跳低：

| 段 | 入面有乜 |
| --- | --- |
| **關** | 冇，全部高度俾返個鍵盤 |
| **候選字** | 選字／選關聯字，太多揀唔晒就撳最右嗰粒 `▼` 拉開變 scroll view。**冇字碼又冇關聯字嗰陣唔會吉住，會出速選字**，撳一下就入 |
| **工具** | `↔` 大細位置、`📋` 貼上、`🎤` 錄音、`😀` emoji、`✨` AI |

打完一個字之後，關聯字會直接出喺候選字嗰條 bar（唔會再迫落九宮格度）。

開咗 emoji 表或者剪貼簿嗰陣，條 bar 最左會多咗粒 **`✖`**，撳佢就返返去普通鍵盤
（就算你平時將條 bar 熄咗，呢兩個模式都一定會出返，唔會出唔返嚟）。

英文滑完一次會**自動彈返出候選字嗰段**（就算你平時擺咗喺工具段或者熄咗），
等你即刻揀第二個可能嘅字。

工具 bar 嗰五粒：

- **`↔` 大細位置** —— 撳一下轉顯示方式；**上下拖 = 拉高／拉低成個鍵盤**，
  左右拖 = 浮動模式搬位。鍵盤永遠貼實螢幕底，唔會整個提起留個窿喺下面。
- **`📋` 貼上** —— 撳一下貼 clipboard；**長撳**下面就變咗 clipboard 歷史 scroll view，
  撳一行就貼，長撳一行就喺歷史度剷咗佢。
- **`🎤` 錄音** —— 系統語音輸入（預設 `yue-Hant-HK` 廣東話），聽緊嘢粒掣會著燈。
- **`😀` emoji** —— 開 emoji 表（下面有）。
- **`✨` AI** —— 要**而家真係揀住一段字**先撳得，唔係就係灰色。

### Emoji

分類 tab（表情／手勢／人物／動植物／食物／活動／旅遊／物件／符號／旗幟）＋「最近用過」，
`assets/emoji.txt` 有成一千四百幾個，載入嗰陣會用 `Paint.hasGlyph()` 篩走部機冇字型嗰啲，
唔會出豆腐字。

**返出去**：撳上面條 bar 嗰粒 `✖`。

**搵字**：撳 emoji 表左上角嘅 `🔍` 就會轉去英文鍵盤，打嘅字**唔會入落個欄**，
淨係即時篩 emoji，夾到嘅出喺上面條 bar 度撳。英文（`cat`）同中文（`貓`）都搵得到 ——
搵字模式嘅英文鍵盤留咗粒「中」，撳咗就用九宮格打中文關鍵字。

### AI 改寫

喺任何 app 揀住一段字，撳 `✨` 就會send去 Gemini，改完直接取代揀咗嗰段。
API key、model（預設 `gemini-3.7-flash`）、prompt（`%text%` = 揀咗嗰段字）
全部喺設定頁入。

### 其他 view

| view | 幾時出 | 特點 |
| --- | --- | --- |
| 英文 | 撳 `🔡`，或者 URI／密碼欄 | QWERTY + Swype 畫線；長撳出變體 popup；`中` 掣隨時轉返中文；底行有 `/`；設定入面可以喺最上面加一行真數字 |
| emoji | 撳工具 bar `😀`（或者左上角嗰粒設定咗做 emoji） | 分類 tab + 用字搵 |
| 數 + 符號 | 撳 `?123` | 五行，第一頁一次過打得晒普通 qwerty 打得出嘅符號 |
| 純數 | 符號頁撳 `123`；或者系統話個欄係 number / phone / datetime | 打完一個數字**唔會**彈返去英文頁，一個接一個咁打得落去。PIN 欄（`numberPassword`）會鎖住，唔畀轉去其他 view |

**所有鍵盤都一樣咁高**（中文四行、英文四／五行、符號五行）：行數多嗰啲每行矮少少，
轉嚟轉去成個窗都唔會跳高跳低。

英文鍵盤仲有：

- **`a` 左邊同 `l` 右邊冇吉位**，成行九粒鍵用盡成行闊度。
- **連撳兩下 `⇧` = capslock**（粒掣變藍，打乜都大階），長撳一樣係 capslock。
- 冇數字行嗰陣，`qwertyuiop` **左上角寫細細個數字、右上角寫符號**；
  開咗數字行就淨係喺數字鍵右上角寫符號，長撳字母亦都唔會再出數字。

**email 欄**（`textEmailAddress` / `textWebEmailAddress`）會自動轉去英文 view，
而且底行會出 `@` 同 `.com`。

## Swype 畫線

英文同中文都支援。起點同終點一定計，中間格靠三個線索一齊決定：

1. **停留** —— 喺格上面慢咗／停低（減速再加速走）
2. **轉角** —— 入格同離格嘅**即時**方向差得夠遠
   （特登唔用「入口→出口」弦線，因為 90° 轉角用弦線只會計到 45°）
3. **字碼表 weight** —— `mapped_table.weight` 話你知呢個字碼有幾常用。
   純幾何唔肯定嗰陣（例如轉角唔夠深）就靠佢加減分：
   加咗呢一碼之後完全冇字 → 直接剔走；係大路字碼 → 加返分。

```
分數 = 幾何信心(0~1) + 0.35 × weight信心(-1~+1)，  ≥ 0.62 就當撳咗
```

中文係**即時出碼**：滑過 `7→9→3` 畫一個直角，等於順序撳咗三下，
每出一碼九宮格嘅內容就即刻變（唔係放手先一次過計），
所以一筆過打晒一個字（甚至去埋選字）係做得到嘅。

英文就相反，放手先至砌字。第一個字會用 composing text 入咗去，
其餘候選字出喺上面條 bar，撳一下就換。

英文滑動仲有兩樣嘢：

- **滑多一次 = 下一個字**：會自動加返個空格再開新字，唔會蓋咗上一個字。
- **會睇 caret 前後**：個欄本身係 `dis|y`（`|` = caret），滑 `p→l→a` 就會出 `display` ——
  淨係搵「`dis` 開頭、`y` 結尾、中間食得住滑過嗰啲字母」嘅字，出錯率低好多。

### 英文詞庫

`assets/en_freq.txt` —— 20 萬個最常用英文字連使用頻率
（來自 `/mnt/d/sync_dev/eng/data/en-most.txt`，篩走非 a-z 之後）。

- **唔會開機或者開鍵盤就載**。第一次見到英文 view 先至喺低優先次序嘅背景 thread 偷偷載，
  實測模擬器 **108ms** 載晒 199,997 個字。未載完就當冇提示，UI 完全唔會 lag。
- 慳記憶體：全部字砌埋做一條 string + offset array，唔係 20 萬個 String object，
  比對直接喺上面行，唔使 substring。
- 揀字 = `使用頻率(ln) − 長度差罰分`，首尾字母一定要啱，中間要係 subsequence。
  即係話幾個字都夾到嗰陣，會揀返**最常用**嗰個
  （`t-h-e` → `the`、`a-n-d` → `and`），中間漏咗鍵一樣夾得返
  （`h-l-o` 都揀得返 `hello`）。

靈敏度（停幾耐、轉幾多度）喺設定入面可以校。

### 英文長撳變體

同一般英文鍵盤一樣：長撳彈出一行變體，**唔好放手**，左右拉去揀，放手先至入。

- **數字鍵**：好似實體鍵盤撳住 shift 咁（`1` → `!`、`2` → `@`…），
  `4` 唔止 `$`，各國銀紙都揀得（`£ € ¥ ¢ ₩ ₹ ₱`）。
- **字母**：冇數字行嗰陣 `qwertyuiop` 會有返數字同符號（`q` → `1` `!`）；
  開咗數字行就淨係剩返各國重音寫法（`a` → `á à â ä ã å ā æ`、`c` → `ç ć č ©`…）
- 揀邊個係睇**手指行咗幾遠**，唔係絕對位置 —— 一彈出就已經揀住第一個，
  所以想要數字就長撳完直接放手，唔使拖。變體多到成行迫貼邊都揀得返第一個。

## 顯示方式（闊 screen 專用）

摺機、平板、打橫嗰陣，如果任由九宮格拉闊，格仔會變成長方形，又難撳又難 swipe。
所以本體超過設定入面嘅 **最大闊度／最大高度** 之後就會定形，剩低嘅位交返俾你決定：

| 模式 | 效果 |
| --- | --- |
| `↔` 拉長 | 用盡成行（細螢幕預設） |
| `⬅` 左留白 | 九宮格貼右，左邊留白 |
| `➡` 右留白 | 九宮格貼左，右邊留白 |
| `✥` 浮動 | 可以左右擺位，直接喺呢粒掣度左右拖就搬得郁 |

工具 bar 最左嗰粒掣即時轉，設定頁都有得揀。

**高度就唔關顯示方式事**：鍵盤永遠用盡分配到嘅高度、永遠貼實底，
想高啲矮啲就喺嗰粒掣度**上下拖**（或者設定頁條「鍵盤高度」）。

## 設定頁（app 本身）

- **字碼資料庫**：browse 揀一個 sqlite 檔案 → **直接覆蓋**而家嗰個（舊版唔會保留）。
  匯入前會檢查有冇 `mapped_table` / `related_candidates_table` / `ts_chinese_table` / `word_meta`
  四張表，唔啱就唔會換。另外有「還原內置字碼表」。
- **鍵盤大細**：按鍵大細、最大闊度、最大高度、**按鍵高度（預設 80%，即係正方格矮 20%）**、
  按鍵空隙、字體大細、顯示方式、浮動左右位置、**鍵盤高度（拉高拉低）**
- **按鍵功能**：左上角嗰粒鍵短撳／長撳分別做乜（速選字／簡體／emoji／貼上／錄音／AI；
  短撳唔准揀「無效」，短撳同長撳亦都唔可以做同一件事）、英文鍵盤要唔要加一行數字
- **滑動輸入**：開關、停留幾耐當撳咗、轉幾多度當轉角
- **AI 改寫**：Gemini API key、model、prompt
- **其他**：簡體輸出、上面條 bar 開機預設係邊段、震動、按鍵聲、長撳時間
- **試打**：四個欄（普通／email／PIN／搜尋）即場試
- **預覽**：實時九宮格，校 size 見到即刻變

## 資料庫

同 Windows 版完全一樣，直接照用 `files/dataset.db`：

| table | 用途 |
| --- | --- |
| `mapped_table` | `id` 0 = 標點，1 = 開關標點，10~999 = 字碼表，1000~1009 = 速選字表；`weight` = 常用度（swipe 判斷會用） |
| `related_candidates_table` | 關聯字，用空格分隔 |
| `ts_chinese_table` | 繁→簡 |
| `word_meta` | 同音字（`ping` / `ping2`） |

字碼會拆成 grapheme cluster（同 C# 嘅 `StringInfo` 一樣），所以 emoji、香港增補字符集都食得住。

九宮格格仔預設**唔係正方**，高度係闊度嘅 80%（正方喺手機上面太高），設定入面可以校返。

`assets/img/` 直接用返 Windows 版 `files/img/` 嘅筆形提示圖（`0_1`~`9_9`）。
Android 版**唔需要** `10_1`~`10_9`，因為關聯字改咗喺上面條 bar 揀。
App icon 都係直接用 `TQ9/logo.png`。

## 起貨

```bash
./gradlew assembleDebug          # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest      # swipe 判定 + 英文詞庫（連真實 20 萬字數據）嘅 unit test
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell ime enable hk.tq9/.ime.TQ9InputMethodService
adb shell ime set    hk.tq9/.ime.TQ9InputMethodService
```

minSdk 26 / targetSdk 36 / Kotlin 2.1 / AGP 8.13。

系統嘅輸入法清單入面得**一個**「九万」（中英數符號係喺鍵盤入面自己切，唔使分 subtype）。

開發／改嘢之前請睇 [AGENTS.md](AGENTS.md)，入面有踩過嘅坑同注意事項。

> 喺模擬器度試，記得 `adb shell settings put secure show_ime_with_hard_keyboard 1`，
> 唔係模擬器有實體鍵盤就唔會彈輸入法出嚟。

## 檔案結構

```

  core/   Q9Db          字碼庫（assets 安裝 / 換 db / weight prefix 統計）

          EnDict        20 萬字英文詞庫 + swipe 砌字
          EmojiDict     emoji 表 + 用字搵（assets/emoji.txt）
          ClipHistory   clipboard 歷史
          AiRewrite     Gemini 改寫揀咗嗰段字
          Prefs         設定
  swipe/  GestureKeyTracker   停留 / 轉角 / weight 三合一嘅中間鍵判定
  ime/    TQ9InputMethodService   IME 主體
          KeyboardBaseView        排版 / 畫鍵 / 掂觸 / 畫線 / 長撳變體 popup / 長撳 ␣ 郁 caret
          ChinesePadView / LatinPadView / SymbolPadView / NumberPadView
          EmojiPadView / ClipboardListView
          OptionBarsView / PadMetrics / Theme / StrokeImages
  ui/     SettingsActivity / MicPermissionActivity
```
