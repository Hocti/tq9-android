九万輸入法 使用說明

九方過期專利 (HK1035043) numpad 中文輸入法，配合滑動、AI 改寫等功能。

啟用輸入法

去「一般」分頁按「啟用 / 停用輸入法」，在系統設定中打開「九万」； 之後按「切換至九万」即可叫出輸入法選單揀選。

中文輸入基本操作

  • 按 1～9 揀碼，逐步縮小候選字範圍；候選字會即時顯示喺格內。
  • 按 0 開關成對標點「」，並將游標移到中間方便輸入。
  • 候選字夠兩頁嗰陣，底行兩格闊嗰粒 0 會變成翻頁鍵。排法有三種，可以喺「一般」分頁嘅「選字翻頁」揀：
    • 大格「下頁」（預設）：成兩格都係「下頁」，容易撳中；長按呢粒就係「上頁」。 呢個狀態下長按 0 嘅成對標點「」會暫時失效，個位改為喺左上角細字寫住「上頁」，頁數（例如 1/10）就搬去右上角。
    • 拆兩粒：上頁、下頁 或 下頁、上頁：拆成兩粒正常闊嘅鍵，左右次序照你揀。 「下頁」左上角寫住而家第幾頁／總共幾頁（例如 1/10）。
  • 攤開同音字表嗰陣，「同音」鍵左上角會寫住而家搵緊邊隻字嘅同音；揀完就會變成嗰隻字正路嘅字碼。
  • 字碼、關聯字、同音字、繁簡對照表全部收錄喺同一個 sqlite 資料庫，可以喺「一般」分頁換走。

左上角按鍵

左上角按鍵嘅短按與長按功能可以喺「一般」分頁自訂， 預設係短按「速選字」、長按「簡體開關」。可選功能包括速選字、簡體開關、表情符號、貼上、語音輸入、AI 改寫。

滑動輸入 (Swype)

喺九宮格上滑過幾個數字鍵，等同順序逐個按下：例如滑過 7→9→3 就等於按咗三下 793，每滑到一個新格即時出碼、即時更新候選字。

中間停留幾耐先當「按落去」、轉幾多度先當「轉角」，兩者都可以喺「一般」分頁微調。

英文與符號鍵盤

  • 英文鍵盤上方固定有一行數字；長按數字鍵可輸入對應符號（同實體鍵盤 Shift 一樣，例如 1 → !）， 長按 4 可揀各國貨幣符號。
  • 長按字母鍵可揀大小寫及各地重音寫法。
  • 長按 , . / 三鍵可揀其餘標點（左上角小字係長按時嘅預設項）。
  • 長按 ?123 可以直接跳去純數字鍵盤，唔使經符號頁。
  • 純數字鍵盤最左一欄係 + - * /， 0 右邊仲有粒 000（一次過打三個 0）。闊度同左右擺位跟返中文九宮格。

表情符號

  • 喺表情符號表撳左上角嘅搵字鍵 ⌕ 就可以打字搵：打嘅字唔會入落輸入框，淨係用嚟篩，夾到嘅表情會出喺上面條候選欄。
  • 搵緊嗰陣底行淨係得「退出表情搜尋」同空白鍵兩粒；撳「退出表情搜尋」就返去表情符號表。

游標與切換輸入法

長按空白鍵 ␣ 唔好放手，上下左右拖動即可移動游標； 切換輸入法改為長按中文鍵盤嘅 Eng 鍵。

工具列

右上角 ☰ 負責開關整條工具列，開啟後會先進入候選字畫面； 之後按工具列最左嘅 ⇄ 可以喺候選字與工具（大小位置、貼上、語音、表情符號、AI）之間切換。 英文與符號頁一律強制顯示工具列。

長按快捷

  • 長按「同音」= 顯示關聯字。
  • 長按 📋 = 顯示剪貼簿記錄。
  • 九宮格 1～9 長按 = 連按兩下（例如長按 7 再拖到 0 放手 = 770）； 滑到最後一格停留夠耐先放手，效果一樣。
  • 純數字鍵盤全頁冇長按功能。

AI 改寫

喺任何 app 入面，揀咗一段文字之後按工具列嘅 ✨ 即可用 AI 改寫： 有揀嘢就淨係改揀咗嗰部分，冇揀就改寫成個輸入框嘅內容。 未輸入 API key、或者喺「AI 改寫」嗰類熄咗個總開關，✨ 按鍵都唔會出現。

「AI」分頁分做語音輸入 (STT)、AI 改寫、AI 設定三大類， 撳個標題就可以收埋／攤開。頭兩類各自有總開關（熄咗「AI 改寫」，工具列就唔會出粒 ✨）， API key 同模型名稱兩邊共用，放喺「AI 設定」：

  • API key：貼上／刪除／顯示，一律經剪貼簿操作。
  • 模型名稱 同 Prompt：Prompt 入面嘅 %text% 會換成要改寫嗰段字。
  • 預設用 Gemini；開啟「使用自訂 API」之後可以打任何接受 JSON 嘅 HTTP POST API （例如 OpenAI、Groq、DeepSeek、OpenRouter、自架 Ollama），要設定 Request URL、 Request Headers、Request Body 範本、 以及喺回應 JSON 入面搵結果嘅回應內容路徑（例如 choices.0.message.content）。 範本入面 %key%／%model%／%prompt% 會自動代入。
  • 成套 AI 設定（provider、key、model、prompt、自訂範本）可以用 「另存新檔」／「載入」／「刪除」存做唔同 profile，方便喺幾個 API 之間切換。

語音輸入

工具列或左上角按鍵設做「語音輸入」，撳落去即可用麥克風輸入文字（首次使用會要求麥克風權限）。

AI 語音輸入：喺「AI」分頁嘅「語音輸入 (STT)」開咗之後， 粒 🎤 就會由系統內置嘅語音輸入改為交俾 AI 辨識。

  • 撳一下開始錄音，再撳一次（或者輕觸畫面）停止；撳住 🎤 唔放手就一路錄，放手即停。
  • 錄音同埋等緊結果嗰陣，成個鍵盤會變灰兼撳唔到：錄音時中間顯示計時器，等緊結果時顯示載入動畫。
  • 開始錄音、錄音完結、成功、失敗會分別發出四種唔同嘅提示音。
  • 送上去嘅唔淨止係段錄音，仲有輸入框而家嘅內容做上下文（純粹畀 AI 知個語境，唔會重複輸出）。
  • 呢個功能淨係 Gemini 做得到（要送成段錄音上去），開咗「使用自訂 API」就用唔到。

其他設定

  • 輸出簡體字：開啟後輸入直接出簡體。
  • 按鍵震動：分 0～3 級 —— 0 = 完全關閉，1 最輕（舊版唯一嗰個力度），數字越大震得越明顯。放手嗰陣會震一下畀你試。部分機款唔支援自訂震幅，嗰啲機淨係感覺到震動時間長短嘅分別。
  • 按鍵聲音：可以開關。
  • 長按時間：決定幾耐算長按，逐 10ms 一格。
  • 字體大細 / 邊框粗幼：調整候選字同鍵盤外觀。
  • 鍵盤高度與闊度：直接喺鍵盤上拖動工具列最左嘅按鍵調整（上下拖 = 高度，左右拖 = 闊度）； 長按同一粒按鍵（撳實唔好拉）就會即刻拉到最闊。中文鍵盤最窄都會保持 320dp 闊。
  • 版本：「一般」分頁最底寫住而家用緊邊個版本（回報問題嗰陣用得着）。

使用習慣統計

每隻字打過幾多次、以及連續兩個字嘅組合，都會記錄喺 usage_stats.db， 同字碼資料庫分開存放（換字碼資料庫唔會影響呢啲記錄）。

  • 常用字排前（預設開）：候選字第一頁會依「同前一個字嘅組合」打過幾多次推前，第九個之後就依該字本身打過幾多次推前。 熄咗就完全依字碼表原本次序，但仍然會繼續記錄次數。
  • 匯出 / 匯入：可以備份或者喺另一部機還原（匯入會覆蓋現有記錄）。
  • 清除記錄：全部刪走並重設為新嘅空白記錄，無法復原。
