三三輸入法使用說明

以數字鍵盤輸入正體中文，並支援滑動輸入、語音輸入及 AI 改寫。

啟用輸入法

在「一般」分頁按「啟用 / 停用輸入法」，然後在系統設定啟用「三三」。再按「切換至三三」，便可從系統選單選用。

中文輸入

  • 按 1～9 輸入字碼。九宮格依數字鍵盤排列：7 8 9 在最上方。
  • 輸入滿三碼，或以 0 結束輸入後，便可選字。
  • 選字時，按空白鍵可選取第一個字；按刪除鍵可取消。
  • 長按 0 可開啟或關閉成對標點。輸入成對標點後，游標會移至中間。
  • 「同音」鍵左下角會顯示當前字碼、正在查詢同音的字，或該字的正確字碼。當前字碼可在設定中隱藏。

選字翻頁

候選字多於一頁時，底行的 0 會變成翻頁鍵。可在「一般 → 選字翻頁」選擇排法：

  • 大格「下頁」（預設）：按下前往下一頁，長按返回上一頁。
  • 雙鍵：將「上頁」和「下頁」分開顯示，並可選擇左右次序。

頁碼以 1/10 形式顯示。使用大格「下頁」時，長按 0 的成對標點功能會在選字期間暫停。

按鍵與長按

  • 左上角按鍵的短按和長按功能均可自訂，包括速選字、簡體開關、表情符號、貼上、語音輸入及 AI 改寫。
  • 長按「同音」鍵可顯示關聯字；長按 📋 可開啟剪貼簿記錄。
  • 九宮格 1～9 長按等於連按兩下。純數字鍵盤不支援長按。
  • 長按空白鍵 ␣ 並拖動，可上下左右移動游標。
  • 長按中文鍵盤的 Eng 鍵可切換輸入法。

滑動輸入

在九宮格上滑過多個數字鍵，等於依序按下這些鍵。例如滑過 7→9→3，就會輸入 793。每確認一碼，候選字都會即時更新。

中間鍵會綜合停留時間、轉向角度及字碼使用頻率判斷。相關門檻可在「一般」分頁調整，一般無須更改。

英文、符號與數字

  • 英文鍵盤固定顯示數字行。長按數字鍵可輸入對應符號；長按 4 還可選擇貨幣符號。
  • 長按字母鍵可選擇大小寫及重音字母。
  • 長按 ,、. 或 / 可選擇其他標點。
  • 長按 ?123 可直接切換至純數字鍵盤。
  • 純數字鍵盤左欄為 + - * /；000 可一次輸入三個 0。

工具列與鍵盤大小

工具列提供關聯字、剪貼簿、語音輸入、表情符號及 AI 功能。工具列常駐時，九宮格右上角顯示 ⇄；關閉常駐後，則以 ☰ 開啟或關閉工具列。

  • 按一下大小位置鍵，可切換拉寬、靠左或靠右。
  • 上下拖動調整鍵盤高度；左右拖動調整鍵盤寬度。
  • 長按但不拖動，可將鍵盤拉至最寬。

表情符號

按表情符號表左上角的 ⌕ 可以文字搜尋。搜尋文字不會寫入輸入欄，只會用於篩選結果。完成後，按「退出表情搜尋」返回表情符號表。

AI 改寫

選取文字後按 ✨，可改寫選取的部分；如未選取文字，則改寫整個輸入欄。未設定 API key 或未啟用「AI 改寫」時，按鍵不會顯示。

  • Prompt 中的 %text% 會替換為待改寫文字。
  • 預設使用 Gemini。如啟用自訂 API，須設定 URL、headers、JSON body 範本及回應內容路徑。
  • %key%、%model% 和 %prompt% 會在送出前自動替換。
  • 可將整套 AI 設定儲存為 Profile，方便切換不同服務。

語音輸入

按 🎤 可使用系統語音輸入。首次使用時，系統會要求麥克風權限。

AI 語音輸入啟用後，🎤 會改用 Gemini 辨識錄音。

  • 按一下開始錄音，再按一下或輕觸畫面停止。按住 🎤 時，放手即停止。
  • 錄音及等待結果期間，鍵盤會變灰並暫停操作。
  • 太短或沒有人聲的錄音不會上傳；最長錄音時間為 90 秒。
  • 輸入欄的現有內容會作為辨識上下文，不會重複輸出。
  • 這項功能只支援 Gemini；啟用自訂 API 時無法使用。

字碼資料庫與筆形圖

字碼、關聯字、同音字及繁簡對照表均儲存在 sqlite 資料庫中，可在「一般」分頁更換或還原內置版本。「檢視目前」會將當前檔案另存，供其他應用程式開啟。

使用習慣統計

usage_stats.db 會記錄每個字的輸入次數，以及相鄰兩個中文字的組合次數。此資料庫與字碼資料庫分開儲存。

  • 常用字排前：第一頁的 9 個字始終保持字碼表次序；從第 10 個字起，才會依與前一個字的組合次數調整。
  • 關閉排序後仍會繼續記錄使用次數。
  • 可匯出、匯入或清除記錄。匯入會覆蓋現有記錄；清除後無法復原。

其他設定

  • 輸出簡體字：將輸入結果轉為簡體字。
  • 按鍵震動：共 0～3 級，0 為關閉。
  • 長按時間：調整長按的觸發時間。
  • 字體大小：中文與英文鍵盤分別調整。
  • 版本資訊：顯示在「一般」分頁底部，方便回報問題。
